# 💰 Expense Tracker

A command-line Expense Tracker application built using **Python** and **JSON**. This project allows users to manage their daily expenses efficiently by providing CRUD (Create, Read, Update, Delete) operations and calculating the total expenses.

---

## 🚀 Features

- ➕ Add a new expense
- 📋 View all expenses
- 🔍 Search for an expense by name
- ✏️ Update an existing expense
- 🗑️ Delete an expense
- 💵 Calculate total expenses
- ⚠️ Exception handling for invalid inputs
- 💾 Stores data permanently using a JSON file

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/aditya95688/Expense-tracker.git
```

2. Navigate to the project folder:

```bash
cd Expense-tracker
```

3. Run the program:

```bash
python expense_tracker.py
```

4. Follow the on-screen menu to manage your expenses.
